# Состояния, формы и связанные данные

1.74 добавляет то, что повторяется на типовых экранах: одинаковые состояния
«пусто / ничего не найдено / ошибка / нет прав», матрицу прав роли, список и
экран в боковой панели по ссылке, ленту событий, сравнение «было / стало»
в журнале аудита, поиск по полям длинной формы и панель несохранённых
изменений. Всё — по желанию: без настройки панель ведёт себя как раньше,
кроме подписи пустого списка (см. [руководство по миграции](../migration-guide.md)).

## Состояния

Состояние занимает место содержимого — таблицы, вкладки, виджета; шапка
экрана и фильтры остаются на месте. Все четыре рисует один компонент
`AdminState` (экспортируется пакетом для своих страниц).

**Пустой список.** По умолчанию — «Записей нет» и «Создать» (если у
пользователя есть право создавать). Свои слова — у ресурса:

```php
use Dskripchenko\LaravelAdmin\Support\EmptyState;

public function emptyState(): ?EmptyState
{
    return EmptyState::make('Городов пока нет', 'Города используются в карточках офисов.', 'Добавить город');
}
```

или у одного встроенного списка (перекрывает ресурс):

```php
Layout::resourceIndex(CallbackResource::class)
    ->scope('new')
    ->emptyState('Новых звонков нет', 'Счётчик в меню обнулён.',
        Link::make('Открыть «В работе»')->href('/admin/screens/calls?tab=work'));
```

Третий аргумент — действие: `null` — «Создать», строка — та же кнопка со
своей подписью, `Action` (ссылка или любое действие панели; скрыто, если
пользователю недоступно), `false` — без действия.
`EmptyState::make(...)->noResults($title, $description)` — свои слова для
«ничего не найдено».

**Ничего не найдено.** Если поиск или фильтры ничего не нашли, состояние
перечисляет их («Статус «ошибка», Создано 01.11–13.11») и предлагает
«Сбросить фильтры».

**Ошибка загрузки.** Причина с сервера, «Повторить» и код запроса
`req 7f3a-91c2 · 13.11 14:40` со «Скопировать код». Код — заголовок
`X-Request-Id`, который панель ставит каждому запросу; сервер возвращает его
в ответе и пишет в контекст лога как `admin_request_id`, так что по коду из
обращения пользователя запрос находится в логе. Так же выглядит экран,
который не загрузился, и встроенная таблица связанных записей.

**Нет прав.** «Раздел «Журнал аудита» недоступен. Нужен ключ
`platform.audit-logs`. Доступ выдаёт администратор панели.» с «Скопировать
ключ». Страница 403 получает название раздела и недостающий ключ от
маршрутизатора (`/forbidden?section=…&permission=…`); ответ 403 API теперь
несёт `payload.permission`.

## Матрица прав — `PermissionMatrix`

```php
use Dskripchenko\LaravelAdmin\Field\PermissionMatrix;

PermissionMatrix::make('permission_keys')
    ->title('Права')
    ->groups(fn () => [
        'Клиенты › Очереди' => [
            'clients.claims' => 'Обращения и претензии',
            'clients.callbacks' => 'Обратные звонки',
        ],
        ['label' => 'Система', 'items' => [
            ['key' => 'platform.roles', 'label' => 'Роли', 'hint' => 'Кто что может'],
        ]],
    ])
    ->extraColumn('ПДн без маски', ['clients.claims' => 'clients.claims.reveal']);
```

Группы — строки, которые сворачиваются (больше пяти — свёрнуты, `->expanded()`
раскрывает), у каждой чекбокс с тремя состояниями и «N из M»; сверху поиск
по названию, подсказке и ключу, «Только выбранные», «Выбрать всё» и «Выбрано
N из M». Вторая колонка (`extraColumn`) — ключ, который выдаётся вместе с
основным (снятие основного снимает и его).

Значение — список ключей. Как его хранит роль (JSON-список, карта Orchid
`{key: 1}`) — дело ресурса: заполните поле в `transformRecord()`/`fill` и
разберите при сохранении. Поле читает и список, и карту. Группы — массив,
замыкание (вызывается при отдаче формы, не при сборке маршрутов) или
`->fromRegistry()` — группы `Admin::permissions()`. `->keys()` — все ключи
матрицы, для правила `Rule::in(...)`.

## Список и экран в боковой панели по ссылке

```php
Link::make('Обращения · 2')
    ->href('/admin/r/claims?filter[phone]=79001234567&scope=open')
    ->inDrawer();                    // или ->target('drawer'); ->inDrawer('lg') — ширина

TableColumn::make('claims_count')->asLink('/admin/r/claims?filter[contract_id]={id}', 'drawer');
```

Ссылка открывает адрес панели в боковой панели поверх текущей страницы:
список ресурса — с поиском (`q`), фильтрами (`filter[...]`), сортировкой и
условием (`scope`, одно из `Resource::scopes()`) из адреса ссылки; экран
(`/admin/screens/{slug}?…`) — встроенным, с этим запросом. Пользователь может
менять фильтры в панели, адрес страницы под ней не меняется. Права
проверяются по маршруту — без них панель показывает «нет прав». «Открыть
страницей» переходит на сам адрес. Любой другой адрес открывается страницей,
внешний — в новой вкладке. Из своего кода:
`import { openInDrawer } from '@dskripchenko/laravel-admin'` →
`openInDrawer('/admin/r/claims?q=…', { title: 'Обращения' })`.

## Лента событий — `Layout::timeline()`

```php
Layout::timeline('events')                     // ключ состояния экрана
    ->types([
        'mail' => ['label' => 'Письма', 'icon' => 'mail', 'tone' => 'info'],
        'process' => ['label' => 'Процессы', 'icon' => 'workflow'],
        'kias' => ['label' => 'КИАС', 'icon' => 'server'],
        'audit' => 'Аудит',
    ])
    ->title('События')
    ->limit(20);
```

Событие — массив: `type`, `title`, `time` (ISO — показывается в локали
панели, или любой текст), `details` (строка или список `['label', 'value']`,
сворачивается под «Подробнее»), `tone` (neutral, info, success, warning,
danger), `icon`, `error: true`, `url`, `linkLabel`, `linkTarget: 'drawer'`.
Тон и значок по умолчанию — от типа. Над лентой — «Все N», чипы типов со
счётчиками и «Только ошибки» (ошибка — `error: true` или тон danger).
Источник — ключ состояния, список или замыкание; данные собирает экран.
`->withoutFilters()` — без чипов, `->emptyText()` — своя фраза пустой ленты.

## Было / стало в журнале аудита

История записи (`AuditTrail`, вкладка истории карточки) показывает короткие
значения как раньше — «было → стало», а длинный текст сравнивает построчно
(одну длинную строку — по словам), JSON — как строки `путь: значение` с
отсортированными ключами. Удалённое — зачёркнуто на красном, добавленное — на
зелёном, неизменные участки свёрнуты («… 12 строк без изменений», раскрываются
щелчком). Компонент `AuditValueDiff` можно взять для своих страниц.

Откат к «было» пакет не делает: восстановления по журналу аудита в нём нет.
Это кнопка-действие проекта (`Button::make('Откатить')->method(...)`), которая
пишет `before` из записи журнала в модель.

## Поиск по полям формы

```php
Layout::tabs([...])->vertical()->persistInQuery('tab')->searchable();
```

Над вкладками появляется поиск: по подписи, подсказке, плейсхолдеру и ключу
поля. Число совпадений — всего и на каждой вкладке (вложенные вкладки тоже
считают), вкладки без совпадений приглушены, если в открытой вкладке
ничего не нашлось — открывается первая с совпадениями. В открытой вкладке
скрыты поля без совпадения и блоки, в которых не осталось полей; найденные
поля отмечены.

## Несохранённые изменения

**Экран.** `Screen::saveMethod()` называет командный метод, который
сохраняет форму экрана:

```php
public function saveMethod(): ?string
{
    return 'save';
}
```

С ним внизу экрана липкая панель «1 несохранённое изменение · Капча › Ключ
сервера · Отменить · Сохранить» (путь — вкладки и блоки над полем), у
изменённого поля — отметка, уход со страницы (меню, ссылка, «Назад») —
с вопросом, закрытие вкладки браузера — с вопросом браузера. «Отменить»
возвращает значения, «Сохранить» вызывает метод экрана.

**Форма ресурса.** Панель «Есть несохранённые изменения · Отмена · Сохранить»
была и раньше; теперь уход с изменённой формы тоже спрашивает (выключается
`features.warnOnUnsavedChanges = false` в манифесте ресурса).

## Мелочи

- `Field::counter(?int $max)` — счётчик символов под полем ввода или текста:
  «27 из 120 символов»; с `$max` поле не даёт ввести больше (правило `max:` для
  сервера добавьте сами).
- `StatsOverviewWidget::stat(..., hint: 'старейшее 26 ч')` — строка под числом.
